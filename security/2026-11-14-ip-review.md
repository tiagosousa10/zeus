# Revisão da exceção ip — TIA-286

Revisão em 14/11/2026, sobre `main@6878d2331a66cf5f56998d42e00b4dd38df31b4e`.

## Evidência atual

O registo npm continua a devolver `ip@2.0.1`, `bittorrent-tracker@11.2.3` (dependência `ip: ^2.0.1`) e `webtorrent@3.0.21` como versões mais recentes. O [advisory GHSA-2p57-rm9w-gvfp](https://github.com/advisories/GHSA-2p57-rm9w-gvfp) afeta `ip.isPublic` até 2.0.1 e não identifica uma versão corrigida.

A inspeção da dependência instalada confirma a importação de `ip` em `bittorrent-tracker/lib/server/parse-udp.js`, para `toString`; não há chamada a `isPublic`/`isPrivate` nessa cadeia. A implementação do Motor cria um cliente WebTorrent; não cria o tracker Server. O servidor HTTP de reprodução do WebTorrent tem outra responsabilidade.

`npm run audit:dependencies` passou: um advisory único revisto, zero não revistos. Isto mantém uma exceção de alcance e versões específicas; não elimina a vulnerabilidade do pacote nem torna limpo o resultado bruto de `npm audit`.

## Decisão

Manter a exceção existente, sem atualizar versões nem introduzir um fork ou override incompatível. O script exige as três versões exatas e rejeita qualquer advisory diferente. Uma alteração de versão, ativação de tracker Server ou uso direto de `ip` exige nova análise antes de aceitar a exceção.

A correção upstream continua pendente; esta revisão não envolve serviços privados, torrents externos, alterações de credenciais ou publicação.
